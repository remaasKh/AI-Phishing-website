# Phishing Website Detection using Random Forest

A small Artificial Intelligence course project that uses Machine Learning to detect phishing websites.

## Project Overview

The project uses a Random Forest Classifier to classify websites as either phishing or legitimate based on different website features.

## Dataset

- 11,055 websites
- 30 website features
- Two classes: Phishing and Legitimate

## Model

We used a Random Forest Classifier.

The dataset was divided into:
- 60% Training
- 40% Testing

## Results

- Testing Accuracy: 96.86%
- Training Accuracy: 99.07%

The close training and testing accuracy indicates that there was no significant overfitting or underfitting.

## Technologies Used

- Python
- Google Colab
- Pandas
- Scikit-learn
- Random Forest

## Project Files

- `AI_Assignment_Phishing_URL.ipynb` — Google Colab notebook containing the code and results.
